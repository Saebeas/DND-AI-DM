Create or update a PC:

If creating new:
1. Ask co-DM for: name, race, class, level, background, ability scores
2. Generate derived stats (HP, AC, proficiencies, saves, skills)
3. Create `characters/pcs/<name>.md` using character-template
4. Add to campaign party roster

If updating:
1. Load existing PC file
2. Apply changes (level up, HP change, new items, spell slots used, conditions)
3. Confirm with co-DM
