Load all D&D context files and prepare for a session:

1. Read `world-state/current-state.md`
2. Read the active campaign file from `campaigns/` (find the most recent or ask which)
3. Read all character sheets from `characters/pcs/`
4. Read `npcs/index.md`
5. Read the latest session log from the active campaign

Present a "Previously on..." recap summarizing:
- Where the party is currently
- What they were doing last session
- Any immediate hooks or threats
- Current quest status

Ask the co-DM: "Ready to continue, or skip ahead to something specific?"
