Create or update an NPC:

If creating new:
1. Ask co-DM for: name, race, role, location, brief description
2. Generate stat block if combat-relevant
3. Create `characters/npcs/<name>.md` using npc-template
4. Add entry to `npcs/index.md`

If updating:
1. Load existing NPC file
2. Apply requested changes (relationship shifts, status updates, new info)
3. Update `npcs/index.md` entry

Always confirm changes with co-DM before saving.
