description: Create a new campaign with party setup
---
Set up a new D&D campaign:

1. Ask co-DM for campaign name, theme, starting level
2. Create `campaigns/<name>/` directory
3. Create campaign files from templates:
   - `campaign.md` — overview, party roster, starting conditions
   - `quest-log.md` — empty quest tracker
   - `decisions.md` — empty decisions log
4. Create session log: `campaigns/<name>/session-log-01.md`
5. Ask co-DM to provide or create player characters
6. Set up `world-state/current-state.md` with starting location
7. If importing an adventure, run `/import-adventure` next
